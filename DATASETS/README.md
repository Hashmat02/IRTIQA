## Variants

- `English`: original English data
- `Urdu`: Urdu translated data
- `Urdu-English_CodeSwitched`: Urdu-English code-switched data

## Datasets

- `DROP`: 10,000 examples per variant
- `SNIPS`: 6,400 examples per variant, split as 5,000 train, 700 dev, 700 test
- `SkillsBench`: 87 tasks per variant
- `AppWorld`: 732 tasks per variant
