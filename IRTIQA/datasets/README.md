# IRTIQA Datasets

Clean index of the final datasets used by IRTIQA.

Each entry is a symlink to the canonical data under `Benchmarks/`.

- `DROP`: 10,000 examples per variant
- `SNIPS`: 6,400 examples per variant
- `SkillsBench`: 87 tasks per variant
- `AppWorld`: 732 tasks per variant

Each dataset has:

- `English`
- `Urdu`
- `Urdu-English_CodeSwitched`
